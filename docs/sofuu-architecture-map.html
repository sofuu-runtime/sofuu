Overview

The Big Picture

Sofuu is a server-side JavaScript runtime built in Rust around a C core. Everything an AI-era app normally installs from npm — LLM streaming, agents, MCP, web search, HTTP — is built in below the language surface.

C Core & the FFI Bridge

Layer 0 and Layer 1. The C core is vendored under deps/ plus the QTSQ store codec; sofuu-ffi wraps every C symbol in safe Rust; sofuu-capi turns the whole runtime into an embeddable C library.

PartSub-partRole in the runtime

deps/quickjsJS engineThe JavaScript engine itself — parses and executes all user code, both at the CLI and inside RLM sandboxes.
deps/libuvevent loopAsync I/O: timers, file I/O, sockets, subprocesses. The Rust rt/loop.rs interleaves its loop with QuickJS microtasks.
deps/llhttpHTTP parsingRequest/response parsing for the HTTP server and client wire paths.
deps/http-parserHTTP parsing (vendored)Legacy parser kept for the server path; bound in sofuu-ffi/src/http_parser.rs.
QTSQ codecbinary store formatLives in its own repo (black-hole-disk); compressed, checksummed containers for the .qtsq stores — brain, sessions, audits.
crates/sofuu-ffi — safe Rust bindings to the C core (Layer 1)
src/lib.rsfacadeThe safe-Rust facade over the whole C core — every other crate calls through here.
src/build.rsbuild scriptCompiles the C core (QuickJS + src/*.c + libuv + curl) into static libraries; guards against QTSQ layout drift.
src/qjs.rsQuickJS bindingsEngine bindings — the M0 keystone of the Rust migration.

The ML Suite — Five Tiny On-Device Models

Each gate is a separate ~8.5k-parameter MLP trained offline by ml-train, baked into the binary, and strictly advise-only: /ml off (or SOFUU_NO_ML=1) restores the mechanical ratios exactly.

Model 1
ml/freshness
Is this material current? Scores staleness of recalled context before it enters the prompt.
Gate
ml/relevance
Pre-retrieval relevance gate — decides what is worth fetching into context at all.
Gate
ml/supervisor
Real-time supervisor over tool calls — flags likely-wasted calls as they happen, with guarded online learning.
Model 4
ml/compaction
When and what to compact — replaces the old fixed 70% cliff with a learned trigger.
Model 5 · newest
ml/alloc
Context-window allocator — fetches the selected model’s real caps first (registry → learned limits → defaults), then allocates per turn: compact point, tool-result cap, recall budget, attach budget, output reserve. Paired with a mechanical Layer-0 clamp and a Layer-1 pre-flight fit ladder so an oversized request never reaches the provider.
Sub-part (file)Role in the suite
ml/net.rsThe generic tiny MLP shared by every gate (24→96→40→1 shape family).
ml/online.rsOnline adaptation of the supervisor’s output layer — confidence-weighted labels, gold = 2.0, two-step adopt/discard, 31-fixture gate.
ml/context.rsShared in-memory context working set — structured view of what the agent loop currently holds.
ml/*/features.rsOne feature extractor per family — 24+ numeric features from caps, history state, and task shape.
ml/*/model.rsPer-family model wrapper — loads baked weights (include_bytes!), runs inference.
ml/*/eval.rsPer-family evaluation harness — fixture gates + property tests (no plan exceeds hard limits).
crates/ml-train The offline trainer: train.rs plus one synthetic-data generator per family (data_alloc / data_compaction / data_freshness / data_relevance / data_supervisor) — 4,810+ labeled trajectories, channel-coverage splits so val/test families never leak into train.

How the pieces connect — the three seams

SeamWhat crosses it
C ↔ Rustsofuu-ffi: QuickJS eval + handles, libuv loop polling, libcurl transfers, QTSQ container read/write.
Rust ↔ JSrt/engine.rs registers every sofuu.* module; shipped.rs embeds the five JS drivers; host_poke wakes the engine thread.
Engine ↔ UIDesktop only: commands.rs in, host.rs events out — the WebView never sees API keys or raw engine state.
