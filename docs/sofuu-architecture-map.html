The Runtime Substrate — sofuu-core/src/rt/

Twenty files that coordinate the event loop, expose Posix I/O primitives to JavaScript, route streaming LLM calls, and enforce model capability limits with dynamic discovery ladders.

Sub-part (file)Role in the runtime substrate
engine.rs / shipped.rsQuickJS engine lifecycle and AOT precompiled bytecode snapshotting (7 shipped .bc drivers) yielding sub-16ms cold start.
loop.rs / timer.rsGlobal libuv event loop driver with bounded microtasks (N=1024), W3C scheduler.yield(), and starvation protection.
zerocopy.rs64-byte aligned SIMD memory bridge (sofuu.memory/buffer): zero-copy Float32Array views and safe detachment.
async_context.rsNative AsyncLocalStorage & sofuu.context: propagates traceId, sessionId, and AbortSignal across async chains with 0 crosstalk.
sandbox.rsHermetic agent sandbox with single-instruction fuel metering via QuickJS interrupt counters, ≤6ms deadlines, and memory caps.
ai.rsThe sofuu.ai streaming router: dispatches across OpenAI, Anthropic, Ollama, and embedded local inference.
memory.rsCMA JavaScript module: features cma_vec_view accepting both Float32Array (zero-copy) and standard JS arrays.
promise.rsPromise ↔ libuv async bridge; async context capture, unhandled-rejection tracking, and Rust future bridging.
fs.rs / process_spawn.rsAsynchronous filesystem operations (sofuu.fs) and streaming child subprocess execution (sofuu.spawn/exec).
http_client.rs / server.rsHigh-throughput fetch() backed by UAF-hardened libcurl and embedded async sofuu.http HTTP/1.1 server.
http_sse.rsJS-facing sofuu.SSEParser streaming parser over incoming server-sent event streams.
mcp.rsModel Context Protocol JS module: client/server lifecycle, tool calling, and resource indexing.
model_caps.rsAuthoritative model capability registry & dynamic HTTP 400 discovery ladder (context windows, thinking tokens).
host_poke.rsThread-safe cross-thread wakeup pipe: lets host UI threads inject events into a running JS loop safely.
session_js.rsSynchronous session-mesh primitives exposed to shipped JS for workspace context sharing.
npm.rs / cjs.rsLightweight npm package resolution and CommonJS compatibility shims for legacy modules.
tui.rsMinimal alt-screen TUI driver powering interactive CLI chat sessions (sofuu chat).

The Edge Inference Engine — sofuu-core/src/infer/

Twenty-eight files delivering high-throughput local LLM execution directly in-process with zero external daemons, supporting Apple Metal GPU acceleration, CPU SIMD, speculative lookahead, and quantized KV caches.

Sub-part (file)ArchitectureRole in local inference
model.rsBlock GraphComposable Transformer Block Graph: executes LLaMA 1/2/3, Qwen 2/2.5/3, Gemma 1/2, Mistral, SmolLM.
metal.rsApple MetalMetal GPU decode backend: unified zero-copy KV cache with single-commit-per-layer batches eliminating GPU stalls.
quant.rsQuantizationSIMD dequantization and GEMV kernels: q4_K, q8_0, q8_K, PQ2_0 (2-bit), PTQ1_0 with 8-act panel sharing.
lookahead.rsSpeculative TreeMulti-branch Jacobi tree speculation: boosts decode speed 1.5x–2.2x (up to 60.3 tk/s on Qwen, 20.1 tk/s on Pi 5).
kivi.rsKIVI / TurboKVAsymmetric 2-bit/4-bit quantized KV cache with rolling F32 residual window; reduces memory bandwidth 4x–8x.
continuous.rsContinuous BatchContinuous batching scheduler: concurrent request handling with decoupled prefill and decode phase metrics.
dynamic_ffn.rsSparse FFNActivation energy gating: prunes 70%+ of SwiGLU down-projection weights dynamically for faster prefill.
snapkv.rsObservation PoolLong-context attention observation pooling: prunes middle prompt KV cache while preserving critical anchor tokens.
weights.rs / mmap.rsZero-Copy IngestionNon-temporal streaming weight loaders (MADV_SEQUENTIAL); ingests multi-gigabyte models in 17–38 ms.
lfm2.rs / pytorch.rsHybrid & UniversalLiquid LFM-2 conv/attention hybrid architecture; zero-copy ingestion of PyTorch (.pt/.pth) and NumPy (.npy) weights.

The ML Decision Suite — Five Tiny On-Device Models

Five specialized ~8.5k-parameter neural networks trained offline with ml-train, baked into the binary, running in ~30 microseconds to guide memory allocation, compaction, and tool safety.

Scores staleness and temporal relevance of recalled context before injection into the prompt.

ml/relevance
Pre-retrieval relevance gate: decides whether a memory query has sufficient signal to fetch.

ml/supervisor
Real-time tool supervisor: detects redundant or looping tool calls with confidence-weighted online learning.
Model 4
ml/compaction
Learned compaction trigger: replaces fixed token threshold cliffs with an intelligent summarization point.
Model 5 · Context Governor
ml/alloc
Context-window allocator: inspects model capabilities (registry → discovered → defaults), allocating per turn: compact point, tool result cap, recall budget, attach budget, and output reserve with mechanical Layer-0 clamp guarantees.

How the Pieces Connect — The Three Seams

SeamWhat crosses it
C/C++ ↔ Rustsofuu-ffi: QuickJS value marshalling, libuv loop polling ticks, libcurl transfers, QTSQ container operations.
Rust ↔ JSrt/engine.rs registers every native sofuu.* module; shipped.rs embeds the 5 JS drivers; host_poke wakes the engine loop.
